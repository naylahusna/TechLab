# Urutan Implementasi SRS — Sprint 2

Dokumen ini mencatat dependensi tingkat tinggi untuk kebutuhan Sprint 2
SRS-00–17. Urutan commit dan pull request terperinci ditentukan tim saat
implementasi.

## Dependensi yang disarankan

1. **Fondasi dan autentikasi — SRS-00–05 (Nayla Husna).** Siapkan Firebase,
   registrasi, login, logout, role-based access, dan profil.
2. **Praktikum dan presensi — SRS-06–12 (Zaidan Ardiyansyah).** Tetapkan
   matriks role terlebih dahulu, lalu kelola kelas, peserta, jadwal, sesi,
   presensi, rekap, dan sinkronisasi.
3. **Izin dan klasifikasi — SRS-13–17 (Arga Yura Danendra).** Sepakati
   kebijakan izin, akses data, dan layanan AI sebelum pengajuan, klasifikasi,
   pengelolaan, keputusan, dan pemantauan status.

Kelompok-kelompok tersebut dapat memiliki pekerjaan paralel setelah kontrak
API, model data, dan izin akses lintas owner disepakati. Ini bukan urutan merge
tetap; setiap pull request harus menyebut dependensi aktualnya.
