## Koordinasi

- Owner bertanggung jawab atas spesifikasi, implementasi, dan verifikasi SRS yang ditugaskan.
- Perubahan lintas bidang dikoordinasikan dengan owner terkait sebelum implementasi.
- Matriks role untuk data kelas, jadwal, sesi, dan izin harus ditetapkan sebelum fitur dirilis.
- Security rules Firebase tetap menjadi lapisan otorisasi data; pemeriksaan UI saja tidak cukup.
- Dokumen SRS menjelaskan target kebutuhan dan tidak menyatakan implementasi sudah selesai.
